Numerical Integration

The problem we will solve

A sensor reports acceleration at discrete times. How far did the object travel?

\[a(t)\longrightarrow v(t)\longrightarrow x(t)\]

Each arrow requires integration. We will approximate these integrals from sampled data and examine the error in our estimates.

Numerical integration methods

We will study:

  • Left and right Riemann sum approximations
  • The trapezoidal rule
  • Simpson’s rule
  • Error bounds for numerical integration
  • Applications to velocity and position

What an acceleration sample can tell us

For one-dimensional motion,

\[v(t)-v(0)=\int_0^t a(s)\,ds,\]

\[x(t)-x(0)=\int_0^t v(s)\,ds.\]

Acceleration has units \(\mathrm{m/s^2}\); integrating with respect to time gives units of \(\mathrm{m/s}\).

The synthetic accelerometer trace

Suppose \(a(t)=1+\frac12t^2\) in \(\mathrm{m/s^2}\) for \(0\leq t\leq4\) seconds.

\(t\) (s) 0 1 2 3 4
\(a(t)\) (\(\mathrm{m/s^2}\)) 1 1.5 3 5.5 9

Assume \(v(0)=x(0)=0\).

The acceleration function is known here so that we can compare our numerical approximations with exact values.

Before calculating

Use the five readings to estimate

\(\Delta v=\int_0^4 a(t)\,dt.\)

Consider:

  • Must \(\Delta v\) lie between \(4\) and \(36\) m/s for this model?
  • Which part of the interval contributes more area?
  • What information is missing between readings?

Notation for numerical integration

Divide \([a,b]\) into \(n\) subintervals of equal width:

\(\Delta x=\dfrac{b-a}{n}\)

The partition points are

\(x_i=a+i\Delta x,\quad i=0,1,\ldots,n.\)

The midpoint of the \(i\)th subinterval is

\(m_i=\dfrac{x_{i-1}+x_i}{2}.\)

For the acceleration example, the interval is \([0,4]\), \(n=4\), and \(\Delta t=1\) second.

Left endpoint rule

The left Riemann sum is

\(L_n=\displaystyle\sum_{i=0}^{n-1}f(x_i)\Delta x.\)

For the sensor readings,

\(L_4=1(1+1.5+3+5.5)=11\ \mathrm{m/s}.\)

Since acceleration is increasing, the left Riemann sum underestimates the integral.

Right endpoint rule

The right Riemann sum is

\(R_n=\displaystyle\sum_{i=1}^{n}f(x_i)\Delta x.\)

For the same trace,

\(R_4=1(1.5+3+5.5+9)=19\ \mathrm{m/s}.\)

Since acceleration is increasing, the right Riemann sum overestimates the integral.

Notice that

\(R_4-L_4=\Delta t[a(4)-a(0)]=8\ \mathrm{m/s}.\)

The Midpoint Rule

The midpoint rule is

\(M_n=\displaystyle\sum_{i=1}^n f(m_i)\Delta x,\)

where \(m_i=(x_{i-1}+x_i)/2\).

The model supplies acceleration values at the midpoints \(t=0.5,1.5,2.5,3.5\):

\(1.125,\quad2.125,\quad4.125,\quad7.125.\)

Therefore,

\(M_4=1(1.125+2.125+4.125+7.125)=14.5\ \mathrm{m/s}.\)

These midpoint values require additional measurements or knowledge of the acceleration function.

The Trapezoidal Rule

The trapezoidal rule approximates the area using trapezoids rather than rectangles.

\[T_n=\frac{\Delta x}{2}\left[f(x_0)+2f(x_1)+\cdots+2f(x_{n-1})+f(x_n)\right]\]

For the acceleration data,

\(T_4=\frac12[1+2(1.5+3+5.5)+9]\)

\(T_4=15\ \mathrm{m/s}.\)

What the trapezoids approximate

Each trapezoid uses the straight line connecting two consecutive data points.

For the model \(a(t)=1+\frac12t^2\):

  • The acceleration graph is concave up.
  • Each connecting line lies above the acceleration graph.
  • The trapezoidal rule overestimates the integral.

The difference between the trapezoidal area and the area under the curve is the approximation error.

Why the Trapezoidal Rule is an average

On \([x_{i-1},x_i]\), the area of the trapezoid is

\(\dfrac{\Delta x}{2}[f(x_{i-1})+f(x_i)].\)

Adding these trapezoidal areas gives

\(T_n=\dfrac{L_n+R_n}{2}.\)

For our example,

\(T_4=\dfrac{11+19}{2}=15\ \mathrm{m/s}.\)

Averaging the left and right sums reduces the error in this example but does not necessarily eliminate it.

An exact check for this model

Since \(a(t)=1+\frac12t^2\),

\[\Delta v=\int_0^4\left(1+\frac12t^2\right)dt =\left[t+\frac{t^3}{6}\right]_0^4=\frac{44}{3}.\]

Thus, \(\Delta v\approx14.667\ \mathrm{m/s}\).

Rule Estimate (m/s)
\(L_4\) 11
\(R_4\) 19
\(M_4\) 14.5
\(T_4\) 15
Exact integral \(\frac{44}{3}\)

Shape predicts error direction

For the increasing, concave-up acceleration function:

Property Consequence
Increasing \(L_4\) underestimates, \(R_4\) overestimates
Concave up \(M_4\) underestimates, \(T_4\) overestimates

The direction of the error and its magnitude are two separate questions.

Absolute and relative error

If \(A\) is the actual value and \(B\) is an approximation, then

\(\text{Absolute error}=|A-B|.\)

The relative error is

\(\text{Relative error}=\dfrac{|A-B|}{|A|},\quad A\ne0.\)

To express relative error as a percentage, multiply by \(100\%\).

For \(T_4=15\) and exact value \(44/3\),

\(\text{Absolute error}=\left|\frac{44}{3}-15\right|=\frac13\ \mathrm{m/s}.\)

Error bounds for numerical integration

Suppose \(|f''(x)|\leq M\) for all \(x\in[a,b]\).

The midpoint rule error satisfies

\(\displaystyle\text{Error in }M_n\leq\frac{M(b-a)^3}{24n^2}.\)

The trapezoidal rule error satisfies

\(\displaystyle\text{Error in }T_n\leq\frac{M(b-a)^3}{12n^2}.\)

These are upper bounds on the absolute errors, not necessarily the actual errors.

Derivation: Linear interpolation

Let \(\ell(x)\) be the line connecting

\((x_{i-1},f(x_{i-1}))\) and \((x_i,f(x_i))\).

For a function with a continuous second derivative, the linear interpolation remainder is

\[f(x)-\ell(x)=\frac{f''(c_x)}{2}(x-x_{i-1})(x-x_i),\]

where \(c_x\) lies between the endpoints.

The integral of \(\ell(x)\) over the subinterval is the area of the corresponding trapezoid.

Error over one subinterval

If \(|f''(x)|\leq M\), then

\[\left|\int_{x_{i-1}}^{x_i}(f(x)-\ell(x))\,dx\right| \leq\frac{M}{2}\int_{x_{i-1}}^{x_i}(x-x_{i-1})(x_i-x)\,dx.\]

Using \(u=x-x_{i-1}\) and \(\Delta x=x_i-x_{i-1}\),

\(\displaystyle\int_0^{\Delta x}u(\Delta x-u)\,du=\frac{(\Delta x)^3}{6}.\)

Therefore, the error on one subinterval is at most

\(\dfrac{M(\Delta x)^3}{12}.\)

The composite trapezoidal error bound

With \(n\) subintervals, the total error satisfies

\(\displaystyle\text{Error in }T_n\leq n\frac{M(\Delta x)^3}{12}.\)

Since \(\Delta x=(b-a)/n\),

\[\text{Error in }T_n\leq\frac{M(b-a)^3}{12n^2}.\]

Doubling \(n\) reduces this error bound by a factor of \(4\), provided the derivative bound remains unchanged.

Test the bound on our model

For \(a(t)=1+\frac12t^2\),

\(a''(t)=1.\)

Thus, \(M=1\), \(b-a=4\), and \(n=4\).

\(\displaystyle\text{Error in }T_4\leq\frac{1(4)^3}{12(4)^2}=\frac13\ \mathrm{m/s}.\)

The actual absolute error is

\(\displaystyle\left|\frac{44}{3}-15\right|=\frac13\ \mathrm{m/s}.\)

The error equals the bound in this particular example.

Choosing the number of subintervals

To guarantee trapezoidal error at most \(\varepsilon\), require

\(\displaystyle\frac{M(b-a)^3}{12n^2}\leq\varepsilon.\)

Solving for \(n\) gives

\[n\geq\sqrt{\frac{M(b-a)^3}{12\varepsilon}}.\]

For the acceleration model and \(\varepsilon=0.01\ \mathrm{m/s}\),

\(n\geq\sqrt{\dfrac{64}{0.12}}\approx23.10.\)

Choose \(n=24\) subintervals.

Simpson’s Rule

Simpson’s rule uses quadratic polynomials to approximate the function.

For an even positive integer \(n\),

\[S_n=\frac{\Delta x}{3}\left[f(x_0)+4f(x_1)+2f(x_2)+\cdots+4f(x_{n-1})+f(x_n)\right].\]

The coefficients follow the pattern

\(1,\ 4,\ 2,\ 4,\ 2,\ \ldots,\ 4,\ 1.\)

Simpson’s rule requires an even number of subintervals.

Where the coefficients come from

On two adjacent subintervals \([x_0,x_2]\), a quadratic polynomial \(p_2(x)\) passes through

\((x_0,f(x_0)),\quad(x_1,f(x_1)),\quad(x_2,f(x_2)).\)

Integrating this polynomial gives

\[\int_{x_0}^{x_2}p_2(x)\,dx =\frac{\Delta x}{3}[f(x_0)+4f(x_1)+f(x_2)].\]

When we combine adjacent pairs of subintervals, shared endpoints receive coefficient \(2\).

Simpson’s Rule on the sensor readings

With \(\Delta t=1\) and \(n=4\),

\[S_4=\frac13[1+4(1.5)+2(3)+4(5.5)+9].\]

Therefore,

\(S_4=\dfrac{44}{3}\ \mathrm{m/s}.\)

This agrees with the exact velocity change.

Simpson’s rule integrates polynomials of degree at most \(3\) exactly.

Simpson’s Rule error bound

Suppose \(|f^{(4)}(x)|\leq M\) on \([a,b]\).

For even \(n\),

\[\text{Error in }S_n\leq\frac{M(b-a)^5}{180n^4}.\]

For our quadratic acceleration model,

\(a^{(4)}(t)=0.\)

Hence \(M=0\), and Simpson’s rule has zero error for this integral.

Comparing numerical integration rules

Rule Required values Error bound depends on
Left and right Endpoints First derivative
Midpoint Midpoints Second derivative
Trapezoidal Endpoints Second derivative
Simpson Endpoints, even \(n\) Fourth derivative

Under appropriate smoothness assumptions, midpoint and trapezoidal errors decrease like \(1/n^2\), while Simpson’s error decreases like \(1/n^4\).

What the error bounds do not include

Numerical integration error bounds concern approximating the integral of a smooth function using exact function values.

Real sensor readings may also contain:

  • Calibration bias or offset
  • Random measurement noise
  • Unobserved changes between samples
  • Timing or initial-condition errors

These sources of error must be considered separately.

First integration: Acceleration to velocity

Apply the trapezoidal rule to consecutive acceleration readings:

\[\hat v_{i+1}=\hat v_i+\frac{\Delta t}{2}(a_i+a_{i+1}),\]

where \(a_i=a(t_i)\) and \(\hat v_0=0\).

\(t\) (s) 0 1 2 3 4
\(\hat v\) (m/s) 0 1.25 3.50 7.75 15.00

Each estimate uses the preceding velocity estimate.

Comparing with exact velocity

For the model \(a(t)=1+\frac12t^2\), with \(v(0)=0\),

\(v(t)=t+\dfrac{t^3}{6}.\)

\(t\) (s) 0 1 2 3 4
Exact \(v\) (m/s) 0 \(7/6\) \(10/3\) \(15/2\) \(44/3\)
\(\hat v-v\) (m/s) 0 \(1/12\) \(1/6\) \(1/4\) \(1/3\)

The accumulated numerical error in velocity increases with time in this example.

Second integration: Velocity to position

Apply the trapezoidal rule to the estimated velocities:

\[\hat x_{i+1}=\hat x_i+\frac{\Delta t}{2}(\hat v_i+\hat v_{i+1}),\]

where \(\hat x_0=0\).

At \(t=4\),

\(\hat x(4)=\frac12[0+2(1.25+3.50+7.75)+15].\)

Therefore,

\(\hat x(4)=20\ \mathrm{m}.\)

Exact position and numerical error

Integrating the exact velocity function gives

\[x(t)=\int_0^t\left(s+\frac{s^3}{6}\right)ds =\frac{t^2}{2}+\frac{t^4}{24}.\]

At \(t=4\),

\(x(4)=\dfrac{56}{3}\approx18.667\ \mathrm{m}.\)

The numerical error is

\(\displaystyle\left|20-\frac{56}{3}\right|=\frac43\approx1.333\ \mathrm{m}.\)

Because velocity is nonnegative here, displacement equals distance traveled.

Sources of the position error

Applying the trapezoidal rule to exact velocity values gives \(58/3\) m.

Contribution Error (m)
Trapezoidal approximation using exact velocity \(2/3\)
Using approximate rather than exact velocity \(2/3\)
Total numerical error \(4/3\)

The second integration includes error already introduced by the first integration.

A bound on two-stage numerical error

Suppose \(|a''(t)|\leq A\) and \(|v''(t)|\leq V\) on \([0,T]\).

For uniform step width \(\Delta t\), sequential trapezoidal integration satisfies

\[|\hat x(T)-x(T)|\leq \frac{VT(\Delta t)^2}{12} +\frac{AT^2(\Delta t)^2}{24}.\]

The first term bounds the error from approximating the position integral.

The second term bounds the propagated error from the approximate velocities.

This assumes exact acceleration samples and exact initial conditions.

A constant acceleration bias

Suppose measured acceleration differs from true acceleration by a constant \(b\):

\(a_{\mathrm{meas}}(t)=a_{\mathrm{true}}(t)+b.\)

Integrating the constant bias gives the velocity error

\(\delta v(t)=bt.\)

Integrating again gives the position error

\(\delta x(t)=\dfrac12bt^2.\)

Thus, position error from a constant acceleration bias grows quadratically with time.

Numerical effect of bias

If \(b=0.020\ \mathrm{m/s^2}\) and \(T=4\ \mathrm{s}\),

\(\delta v=0.020(4)=0.080\ \mathrm{m/s},\)

\(\delta x=\dfrac12(0.020)(4)^2=0.160\ \mathrm{m}.\)

For the same constant bias over \(20\) seconds,

\(\delta x=\dfrac12(0.020)(20)^2=4.0\ \mathrm{m}.\)

Does a smaller step eliminate error?

Error source Effect of decreasing \(\Delta t\)
Smooth-function trapezoidal error Decreases approximately as \((\Delta t)^2\)
Constant acceleration bias Position error remains \(\frac12bT^2\)
Unobserved motion between samples Requires additional assumptions

More frequent sampling improves numerical approximation under appropriate smoothness assumptions, but it does not automatically remove systematic measurement bias.

Key ideas

  • Select a numerical integration rule based on the available function values.
  • Midpoint and trapezoidal approximations use different sampling locations.
  • Simpson’s rule requires an even number of subintervals.
  • Derivative bounds provide guarantees on numerical integration error.
  • When acceleration is integrated twice, errors can accumulate.
  • Measurement error and numerical approximation error must be considered separately.
