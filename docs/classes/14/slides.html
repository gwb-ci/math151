What is an Improper Integral?

In this section, we define integrals over an infinite interval as well as integrals of functions containing a discontinuity on the interval.

Integrals of these types are called improper integrals.

We examine several techniques for evaluating improper integrals, all of which involve taking limits.

Integrating over an Infinite Interval

To integrate a function over an infinite interval, we consider the limit of the integral as the limit increases without bound.

If \(f(x)\) is continuous over \([a,+\infty)\), then

$ a^{+} f(x),dx={t+}_a^t f(x),dx$

provided this limit exists.

Infinite Interval to the Left

If \(f(x)\) is continuous over \((-\infty,b]\), then

$ {-}^{b} f(x),dx={t-}_t^b f(x),dx$

provided this limit exists.

In each case, if the limit exists, then the improper integral is said to converge.

If the limit does not exist, then the improper integral is said to diverge.

Infinite Interval in Both Directions

If \(f(x)\) is continuous over \((-\infty,+\infty)\), then

$ {-}^{+} f(x),dx={-}{0}f(x),dx+_{0}{+}f(x),dx$

provided that both integrals converge.

If either one or both of these two integrals diverge, then

$ _{-}^{+} f(x),dx$

diverges.

Example 3.47: Finding an Area

Determine whether the area between the graph of \(f(x)=\frac{1}{x}\) and the \(x\)-axis over the interval \([1,+\infty)\) is finite or infinite.

$ A=_1^,dx$

\(=\lim_{t\to+\infty}\int_1^t\frac{1}{x}\,dx\)

Example 3.48: Finding a Volume

Find the volume of the solid obtained by revolving the region bounded by the graph of \(f(x)=\frac{1}{x}\) and the \(x\)-axis over \([1,+\infty)\) about the \(x\)-axis.

Using the disk method,

$ V=_1{+}\frac{1}{x2},dx$

\(=\pi\lim_{t\to+\infty}\int_1^t\frac{1}{x^2}\,dx\)

\(=\pi\lim_{t\to+\infty}\left(-\frac{1}{x}\right)\bigg|_1^t\)

\(=\pi\lim_{t\to+\infty}\left(-\frac{1}{t}+1\right)=\pi\)

Gabriel’s Horn

Although the area of the region between the \(x\)-axis and the graph of \(f(x)=1/x\) over \([1,+\infty)\) is infinite, the volume of the solid generated by revolving this region about the \(x\)-axis is finite.

The solid generated is known as Gabriel’s Horn.

Example 3.51

Evaluate $ _{-}{+}xex,dx$.

Start by splitting up the integral:

$ {-}{+}xex,dx={-}{0}xex,dx+_{0}{+}xex,dx$

If either integral diverges, then

$ _{-}{+}xex,dx$

Example 3.51: First Integral

$ {-}{0}xex,dx={t-}_t0xex,dx$

\(=\lim_{t\to-\infty}(xe^x-e^x)\bigg|_t^0\)

Integrating a Discontinuous Integrand

Now let’s examine integrals of functions containing an infinite discontinuity in the interval over which the integration occurs.

If \(f(x)\) is continuous over \([a,b)\), then

$ a^b f(x),dx={tb-}_at f(x),dx$

If \(f(x)\) is continuous over \((a,b]\), then

$ a^b f(x),dx={ta+}_tb f(x),dx$

Discontinuity Inside the Interval

If \(f(x)\) is continuous over \([a,b]\) except at a point \(c\) in \((a,b)\), then

$ _a^b f(x),dx=_a^c f(x),dx+_c^b f(x),dx$

provided both integrals converge.

If either of these integrals diverges, then

$ _a^b f(x),dx$

diverges.

Example 3.52

Evaluate $ _0^4 ,dx$.

The function \(f(x)=\frac{1}{\sqrt{4-x}}\) is continuous over \([0,4)\) and discontinuous at \(4\).

$ 0^4 ,dx={t-}_0t,dx$

\(=\lim_{t\to4^-}\left(-2\sqrt{4-x}\right)\bigg|_0^t\)

\(=\lim_{t\to4^-}\left(-2\sqrt{4-t}+4\right)=4\)

The improper integral converges.

Example 3.53

Evaluate $ _0^2 xx,dx$.

Since \(f(x)=x\ln x\) is continuous over \((0,2]\) and is discontinuous at zero,

$ 0^2 xx,dx={t+}_t2 xx,dx$

Using integration by parts,

\(=\lim_{t\to0^+}\left(\frac{1}{2}x^2\ln x-\frac{1}{4}x^2\right)\bigg|_t^2\)

\(=\lim_{t\to0^+}\left(2\ln2-1-\frac{1}{2}t^2\ln t+\frac{1}{4}t^2\right)\)

\(=2\ln2-1\)

The improper integral converges.

Example 3.54

Evaluate $ _{-1}{1}\frac{1}{x3},dx$.

Since \(f(x)=1/x^3\) is discontinuous at zero,

$ {-1}{1}\frac{1}{x3},dx={-1}{0}\frac{1}{x3},dx+_01\frac{1}{x3},dx$

Therefore, $ _{-1}{1}\frac{1}{x3},dx$ diverges.

A Comparison Theorem

It is not always easy or even possible to evaluate an improper integral directly.

By comparing it with another carefully chosen integral, it may be possible to determine its convergence or divergence.

Suppose \(f(x)\) and \(g(x)\) are continuous over \([a,+\infty)\) and

\(0\le f(x)\le g(x)\)

for \(x\ge a\).

Theorem 3.7: A Comparison Theorem

Let \(f(x)\) and \(g(x)\) be continuous over \([a,+\infty)\).

Assume that \(0\le f(x)\le g(x)\) for \(x\ge a\).

  1. If $ _a^{+} f(x),dx=+$, then $ _a^{+} g(x),dx=+$.

  2. If $ _a^{+} g(x),dx=L$, where \(L\) is a real number, then $ _a^{+} f(x),dx=M$ for some real number \(M\le L\).

Example 3.55

Use a comparison to show that

$ _1{+}\frac{1}{xex},dx$

converges.

We can see that

\(0\le \frac{1}{xe^x}\le \frac{1}{e^x}=e^{-x}\)

so if $ _1{+}e{-x},dx$ converges, then so does

$ _1{+}\frac{1}{xex},dx$.

Example 3.55: Comparison Integral

$ 1{+}e{-x},dx={t+}_1^t e^{-x},dx$

\(=\lim_{t\to+\infty}(-e^{-x})\bigg|_1^t\)

\(=\lim_{t\to+\infty}(-e^{-t}+e^{-1})\)

\(=e^{-1}\)

Since $ _1{+}e{-x},dx$ converges, so does

$ _1{+}\frac{1}{xex},dx$.
